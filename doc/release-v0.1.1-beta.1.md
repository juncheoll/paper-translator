# Paper Translator v0.1.1-beta.1

첫 공개 베타 이후 PDF 읽기 순서, 번역 패널, 배치 번역과 Windows Docling 캐시 저장을 개선한 베타입니다.

## 변경 사항

- 번역 패널 왼쪽 경계선을 드래그해 너비만 조절합니다. 높이는 화면에 맞춰 유지하고 너비는 저장합니다.
- Docling이 판별한 `page_header`·`page_footer`를 읽기 순서 계산 전에 제외합니다. 세로 arXiv 등록 표기가 본문 단락을 끊거나 번역·검색 문맥에 섞이는 문제를 수정했습니다.
- 이전 본문 파싱은 갱신하면서 Docling 분석 결과, 수동 영역 수정과 원문 하이라이팅 연결을 유지합니다. 원문이 같은 문장의 번역과 검색 벡터도 재사용합니다.
- 번역 요청당 최대 문장 수를 4개에서 10개로 늘렸습니다. 원문 합계 900자, 공통 문맥과 출력 1,024토큰 한도는 배치 전체가 공유합니다. 형식이 잘못되거나 출력이 잘린 배치는 기존처럼 문장별로 재시도합니다.
- Windows에서 열린 임시 파일을 교체하던 Docling 캐시 저장 방식을 수정했습니다. 파일을 닫은 뒤 결과를 반영하고, 실패한 임시 파일도 정리합니다.
- 설치 ZIP의 업데이트 방법과 Docling 도우미 갱신 안내를 추가했습니다.

## 설치와 업데이트

이 릴리스의 **`paper-translator-v0.1.1-beta.1.zip`**을 받아 전체 압축 해제하세요. GitHub의 자동 생성 `Source code.zip`은 개발용 소스입니다.

처음 설치하는 경우 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 눌러 압축을 푼 폴더 안의 **`extension/`**을 선택합니다.

기존 사용자는 새 ZIP의 `extension/` 내용을 Chrome에 등록된 기존 폴더에 교체한 뒤 확장의 **새로고침(↻)**을 누르세요. 같은 확장 ID를 유지하므로 기존 설정을 이어 씁니다. 열려 있던 PDF 탭도 닫았다 다시 여세요. 확장 버전 이름은 `0.1.1-beta.1`입니다. Chrome의 **업데이트** 버튼은 압축 해제한 폴더의 파일을 새로 내려받지 않습니다.

로컬 Docling 사용자는 PDF 탭을 닫고 설정에서 Docling을 중지한 뒤, **새 ZIP에 들어 있는 운영체제별 도우미 설치 파일을 다시 실행**해야 서비스 코드 수정도 적용됩니다. Windows에서는 `tools/install-docling-windows.cmd`를 실행합니다. 기존 모델과 분석 캐시는 유지됩니다. 설치 후 설정에서 **분석 준비**를 누르고 PDF를 다시 여세요.

## 확인 범위

JavaScript 테스트 439개와 Python 도우미·패키징 테스트 46개, 프로덕션 빌드와 설치 ZIP 구성을 확인했습니다. Windows 캐시 수정은 파일 공유 규칙을 재현한 회귀 테스트로 검증했으며, 실제 Windows PC의 HTTP 500 문제가 해결되는지는 추가 확인이 필요합니다.

새 PC 최초 설치, 실제 Chrome 확장에서의 WebGPU 전체 추론, Windows/Linux 도우미 설치와 다양한 논문의 파싱은 베타 사용자와 계속 확인합니다. 브라우저 모델과 API 서버는 ZIP에 포함하지 않습니다. 기존 사용 안내와 서버 설치 문서는 ZIP에 함께 들어 있습니다.
