# Paper Translator v0.1.0-beta.1

PDF 논문의 문맥을 참고해 문장 단위로 번역하는 첫 공개 베타입니다. 번역·RAG 임베딩·Docling 영역 분석을 각각 브라우저/로컬 또는 서버에서 실행하도록 선택할 수 있습니다.

## 주요 기능

- 문장 단위 번역, 원문 단락·섹션별 표시, 두 단 읽기 순서와 페이지 경계의 문장 연결.
- 논문 전체의 검색용 임베딩과 주변 문맥을 활용한 번역. 번역과 임베딩의 API 주소·모델·키를 독립 설정.
- 수식·표의 원본 표시, 본문 수학 기호 보존, 변수 설명 근거 툴팁, 원문과 번역의 양방향 하이라이팅.
- 문장·제목별 재번역 세 가지와 이전 번역 복원. 재번역 실패 시 기존 결과 유지.
- Docling CPU 분석의 로컬 도우미·서버 API 연결, 분석 캐시, 영역 분류·제외·경계·분할 수정과 저장.
- 브라우저 모델 다운로드·준비·메모리 해제·삭제, 작업 취소와 연결 오류 표시.

## 설치

1. 이 릴리스의 **`paper-translator-v0.1.0-beta.1.zip`**을 받아 전체 압축 해제합니다. 자동 생성된 `Source code.zip`을 설치 파일로 사용하지 마세요.
2. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 눌러 압축을 푼 폴더 안의 **`extension/`**을 선택합니다.
3. 확장 아이콘 → **실행 설정**에서 세 기능의 실행 위치·모델·주소를 각각 지정하고 저장합니다. 서버는 연결 확인, 브라우저 모델은 다운로드·준비 후 PDF를 열어 **이 페이지 번역**을 누릅니다.

Docling을 서버에서 사용하면 사용자 PC에 Python이나 Docling 도우미를 설치할 필요가 없습니다. 로컬 CPU 분석을 선택한 경우 ZIP에 포함된 `tools/`의 운영체제별 도우미 설치 파일을 사용하세요. 기존 MouseTooltipTranslator의 도우미와 별도 등록입니다.

API 서버와 모델 가중치는 배포 ZIP에 포함하지 않습니다. 서버 주소·모델명·인증 정보는 운영자에게 받거나 직접 준비하세요. 인증을 사용하지 않는 Docling 서버에는 API 키를 비워둘 수 있습니다. 서버 운영 시 접근 제한과 PDF 전송·보존 정책을 정해야 합니다.

## 베타 확인 범위

단위 테스트와 합성 문서, 실제 원격 Ollama 번역·임베딩, CPU Docling 분석·캐시·인증 경로를 확인했습니다. 다음 항목은 베타 사용자와 추가 확인이 필요합니다.

- 새 PC의 최초 설치와 기존 개발 환경에 의존하지 않는 실행.
- 실제 Chrome 확장 환경의 브라우저 WebGPU 전체 추론 경로.
- Windows/Linux에서의 로컬 도우미 설치·실행.
- 여러 사용자 동시 사용과 다양한 논문의 파싱 정확도.

Chrome 116 이상이 필요하며 브라우저 AI는 호환되는 WebGPU·하드웨어 가속이 필요합니다. 텍스트가 없는 스캔 PDF의 OCR은 제공하지 않습니다. GitHub ZIP 배포는 개발자 모드 설치와 수동 업데이트 방식입니다.

설정·캐시·수동 영역 수정은 새 확장에 저장되며 이전 확장에서 자동으로 이전되지 않습니다. 원격 번역에는 문장과 참고 문맥, 원격 임베딩에는 논문 텍스트 청크, 원격 Docling에는 PDF 전체를 전송합니다. API 키는 확장 로컬 저장소에 보관하고 동기화하지 않습니다.

사용 안내와 서버 설치·개인정보 문서는 설치 ZIP에 포함되어 있습니다. 문제를 보고할 때 운영체제·Chrome 버전, 각 기능의 실행 위치, 재현 단계와 오류 문구를 알려주세요. API 키와 비공개 논문 내용은 공개 이슈에 올리지 마세요.
