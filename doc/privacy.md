# Paper Translator 개인정보 안내

Paper Translator는 사용자가 지정한 실행 위치에 따라 데이터를 처리합니다. 별도 분석·광고·텔레메트리 서비스를 추가하지 않습니다.

| 선택 | 전송하는 데이터 | 목적지 |
|---|---|---|
| 브라우저 번역·임베딩 | 초기 모델 다운로드 요청. 추론 대상 텍스트는 기기 내부 처리 | 고정 리비전의 Hugging Face 모델 저장소 |
| API 번역 | 대상 문장, 제목·주변 단락·검색한 관련 문맥, 대상 언어 | 설정한 번역 API |
| API 임베딩 | 논문 전체를 나눈 텍스트 청크와 검색어 | 설정한 임베딩 API |
| 로컬 Docling | 전체 PDF를 loopback API로 전달 | 내 PC의 CPU 도우미 |
| 서버 Docling | 전체 PDF | 설정한 Docling API |

설치기는 GitHub의 고정 uv 바이너리를 SHA-256으로 확인하고 Python·PyPI/PyTorch 패키지를 받습니다. 모델 준비는 Hugging Face에서 Heron 가중치를 받습니다. 이후 준비된 모델은 오프라인 추론에 사용할 수 있습니다.

설정과 API 키는 Chrome 확장 `storage.local`에 저장합니다. Chrome 동기화 저장소로 복사하지 않습니다. 번역·색인·수동 영역 수정은 IndexedDB, 패널 크기는 localStorage, 브라우저 가중치는 런타임 캐시에 남습니다. Docling 전송용 임시 PDF Blob은 완료·취소 시 삭제하고 만료된 업로드도 청소합니다. 비정상 종료 시 만료 청소 전까지 남을 수 있습니다.

Docling 서비스는 원본 PDF를 처리 중 메모리에 두며 원본 파일을 디스크에 저장하지 않습니다. 서버 캐시에는 문서 해시와 영역·셀 좌표·분류·모델 및 런타임 식별정보가 남습니다. 서비스 로그에는 처리 상태·오류가 남을 수 있습니다. 서버 운영자와 별도 프록시는 요청을 기록할 수 있으므로 운영 정책을 확인하세요.

각 원격 서버의 인증·보존 기간·삭제 방법은 운영자가 관리합니다. HTTPS를 권장합니다. API 키를 URL에 넣지 말고 인증란에 입력하세요. 오류에 키를 표시하지 않으며 요청 URL의 사용자 정보·쿼리는 허용하지 않습니다.

확장 제거 시 확장 저장소는 삭제됩니다. Docling 도우미와 서버의 모델·캐시는 별도로 남습니다. 도우미 설치 스크립트의 `--uninstall`은 등록과 도우미 구성을 제거하고 데이터는 보존하며, 데이터까지 삭제하려면 `--remove-data`도 지정합니다. 동작 중인 프로세스나 다른 서비스는 원래 실행 위치에서 중지하세요.

브라우저 권한 중 사이트 액세스는 임의의 PDF와 사용자가 지정하는 API 서버를 읽기 위해, tabs는 PDF 열기와 전환을 위해, offscreen은 브라우저 모델의 실행 공간을 위해, nativeMessaging은 로컬 Docling 도우미 제어를 위해 사용합니다. 일반 웹 페이지의 내용은 번역·수집하지 않습니다.
