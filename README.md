# Paper Translator

PDF 논문의 문맥을 참고해 문장 단위로 번역하는 Chrome 확장프로그램입니다. 번역, RAG 임베딩, Docling 레이아웃 분석의 실행 위치를 각각 선택합니다. 예를 들어 번역은 연구실 서버, 임베딩은 브라우저, Docling은 내 PC의 CPU에서 실행할 수 있습니다.

MouseTooltipTranslator에서 개발·검증한 PDF 처리 로직을 이관하고, 확장 진입점·설정·PDF 열기·브라우저 AI 호스트를 PDF 전용으로 새로 구성했습니다. 일반 웹 툴팁·입력창 번역·자막·음성·OCR·단어장 기능은 포함하지 않습니다. 원본 저장소와 설치 환경은 변경하지 않습니다.

## 베타 다운로드

[v0.1.0-beta.1 설치 ZIP 다운로드](https://github.com/juncheoll/paper-translator/releases/download/v0.1.0-beta.1/paper-translator-v0.1.0-beta.1.zip) · [릴리스 안내](https://github.com/juncheoll/paper-translator/releases/tag/v0.1.0-beta.1)

**Releases에 첨부된 `paper-translator-v0.1.0-beta.1.zip`을 받으세요.** GitHub가 자동으로 제공하는 `Source code.zip`은 개발용 소스이며 바로 설치하는 확장 ZIP이 아닙니다. 설치 ZIP에는 `extension/`, Docling 도우미·서버용 `tools/`, 사용 문서가 함께 들어 있습니다.

이 릴리스는 연구실 동료들과 새 PC 설치·실제 논문 사용을 확인하는 베타입니다. 새 PC 최초 설치, 실제 Chrome의 브라우저 WebGPU 전체 경로, Windows/Linux 도우미 설치는 추가 검증이 필요합니다. 오류를 보고할 때 운영체제·Chrome 버전·실행 위치와 오류 문구를 적고 API 키나 비공개 논문 원문은 제외하세요.

## 시작하기

1. 배포 ZIP을 **전체 압축 해제**합니다. Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 눌러 `extension/` 폴더를 선택합니다. 소스에서 빌드했다면 `build/`를 선택합니다.
2. 확장 아이콘 → **실행 설정**을 엽니다. 세 기능의 실행 위치·주소·모델을 각각 지정하고 **설정 저장**을 누릅니다.
3. 서버를 선택했다면 각 카드의 **연결 확인**으로 확인합니다. 브라우저 실행은 해당 모델의 **다운로드·준비**를 먼저 완료합니다.
4. 논문 PDF에서 확장을 실행하거나 PDF 주소를 입력합니다. 로컬 파일은 **PDF 파일 열기** 창에서 선택하거나 끌어놓습니다.
5. 문서 준비 후 오른쪽 패널의 **이 페이지 번역**을 누릅니다. 첫 준비에는 문서 전체의 영역 분석과 임베딩이 포함됩니다. 이후 결과는 캐시에서 재사용합니다.

Chrome 116 이상이 필요하며 브라우저 AI는 호환되는 WebGPU와 하드웨어 가속도 필요합니다. 웹 PDF 자동 열기를 끌 수 있습니다. 일부 브라우저 PDF 페이지에서는 자동 전환이 제한될 수 있으므로 확장 아이콘의 **현재 PDF 번역하기**를 사용하세요. `file://` 주소로 직접 연 파일을 자동 전환하려면 확장 상세 설정의 **파일 URL에 대한 액세스 허용**이 필요합니다. 파일 선택·끌어놓기는 그 설정 없이 사용할 수 있습니다.

### 확장 업데이트

압축 해제해서 설치한 확장은 Chrome의 **업데이트** 버튼으로 새 ZIP을 내려받지 않습니다. `chrome://extensions` → Paper Translator **세부정보**에서 등록한 폴더를 확인하고, 최신 ZIP의 `extension/` 내용을 그 폴더에 교체한 뒤 해당 확장의 **새로고침(↻)**을 누르세요. 이 방식은 기존 설정을 유지합니다. 열려 있던 PDF 탭도 닫았다 다시 여세요. 소스에서 사용하는 경우에는 `npm run build`로 갱신한 `build/`가 Chrome에 등록된 폴더여야 합니다.

## 독립 실행 설정

| 기능 | 이 기기 | API 서버 |
|---|---|---|
| 번역 | wllama, Hy-MT2 1.8B Q8 | Ollama 또는 OpenAI 호환 Chat Completions |
| 임베딩 | wllama, EmbeddingGemma 300M Q8 | Ollama `/api/embed` 또는 OpenAI 호환 `/embeddings` |
| Docling | 별도로 설치한 CPU 도우미, 자동 시작 지원 | 이 프로젝트의 Docling 레이아웃 API |

기본 번역 주소는 `http://localhost:11434/v1`, 모델은 `hy-mt2:1.8b-q8`입니다. 기본 임베딩 주소는 `http://localhost:11434`, 모델은 `embeddinggemma`, API 형식은 Ollama입니다. **번역 주소를 바꿔도 임베딩 주소는 바뀌지 않습니다.** 같은 서버를 쓰려면 두 카드에 각각 입력하세요. 로컬 Ollama도 API 방식에서 localhost 주소로 연결합니다.

OpenAI 호환 임베딩은 `/v1` 같은 API 기본 주소를 입력합니다. 서버에서 모델 이름과 인증 요구사항을 확인하세요. 연결 확인은 서버가 제공하는 모델 목록을 검사하며 실제 논문의 번역 품질·처리 용량까지 보장하지 않습니다. 서버가 모델 목록 API를 제공하지 않으면 실제 요청 지원 여부를 운영자에게 확인하세요.

브라우저 모델 준비는 가중치 다운로드와 메모리 로딩까지 수행합니다. 중지·메모리 해제는 가중치 캐시를 남기고, 모델 삭제는 내려받은 가중치도 삭제합니다. 메모리 사용을 줄이기 위해 한 모델만 상주하며 번역·임베딩 작업 사이에서 교체합니다. 최초 다운로드는 번역 약 1.91 GB, 임베딩 약 334 MB입니다. 모델 파일을 배포 ZIP에 넣지 않습니다.

## Docling

### 내 PC에서 분석

배포 ZIP의 `tools/` 폴더를 포함해 전체 압축을 푼 다음 실행합니다.

- macOS 14 이상 Apple Silicon: `tools/install-docling-macos.command`
- Windows x64: `tools/install-docling-windows.cmd`
- Linux x64: `sh tools/install-docling-linux.sh`

설치기는 사용자 전용 Python·가상환경·Chrome Native Messaging 등록을 만듭니다. 시스템 Python과 기존 번역 확장의 도우미는 바꾸지 않습니다. 인터넷 연결이 필요하며 운영체제가 실행을 차단하면 파일 출처를 확인하고 터미널에서 실행하세요. macOS에서는 `sh tools/install-docling-macos.command`로 실행할 수 있습니다.

설치 후 새 확장의 설정에서 **상태 확인 → 분석 준비**를 누릅니다. Heron 모델을 다운로드하고 CPU에 로딩합니다. PDF 자동 시작은 이미 내려받은 모델만 사용합니다. 최초 준비는 라이브러리 초기화 때문에 오래 걸릴 수 있습니다. **중지·메모리 해제** 후에도 모델·분석 캐시는 유지됩니다.

도우미 업데이트는 PDF 탭을 닫고 설정에서 Docling을 중지한 뒤, 새 ZIP의 운영체제별 설치 파일을 다시 실행하세요. 설치 파일이 별도 설치 경로의 Python 서비스를 갱신하며, 이미 내려받은 모델과 분석 캐시는 유지합니다. 완료 후 분석 준비를 누르고 PDF를 다시 여세요.

새 도우미는 `com.papertranslator.docling`, 로컬 API는 `127.0.0.1:8876`을 사용합니다. 이전 MouseTooltipTranslator 도우미와 별도로 설치해야 합니다. 기존 8875 서비스는 종료하지 않습니다. 다른 Chrome 확장 ID로 배포하면 해당 ID로 설치 등록을 갱신해야 합니다.

### 서버에서 분석

설정에서 Docling을 서버 실행으로 바꾸고 API 기본 주소와 서버가 요구하는 토큰을 입력합니다. 인증 없이 운영하는 서버라면 API 키를 비워둡니다. 예: `https://papers.example.org/docling`. `/v1/info`까지 붙이지 않습니다. 이 프로젝트의 `tools/docling_service.py`가 제공하는 geometry API이며 공식 Docling Serve의 변환 API와 직접 호환되지 않습니다.

서버 모드에서는 내 PC의 Python·Docling 설치가 필요 없습니다. 원본 PDF 전체가 서버로 전송되고, 서버는 본문·제목·캡션·그림 등의 좌표를 반환합니다. PDF.js 원문 텍스트와 좌표를 사용하므로 하이라이팅·수동 영역 수정·그림 및 각주 제외는 유지됩니다. 서버 분석 실패 시 캐시 또는 기존 규칙 기반 추출로 전환하며 패널에 상태를 표시합니다.

서버 설치·nginx·인증 구성은 [서버 운영 안내](doc/server.md)를 참고하세요.

## PDF 사용

- 번역은 문장 단위이며 패널에는 원문 단락·섹션에 맞춰 묶어 표시합니다. 두 단 읽기 순서와 페이지 경계에서 이어지는 문장을 처리합니다.
- 연속된 문장은 한 요청에 최대 10개씩 묶습니다. 원문 합계 900자와 공통 문맥·출력 한도는 배치 전체에 적용되므로 긴 문장은 더 작은 묶음으로 처리합니다.
- 번역문에 마우스를 올리면 원문을 강조하고 클릭하면 해당 위치로 이동합니다. 원문에서 마우스를 올리면 대응하는 번역문을 표시합니다. 연동 강조와 원문 변수 툴팁은 각각 끌 수 있습니다.
- 수식·표는 PDF에서 렌더링한 모습을 표시하고, 본문의 수학 기호도 보존합니다. 변수 툴팁은 본문에서 찾은 설명 근거를 보여줍니다.
- 문장·제목을 우클릭하면 세 가지 재번역 방식과 이전 번역 복원을 사용할 수 있습니다. 실패하면 기존 번역을 유지합니다.
- 패널 왼쪽 경계선을 드래그해 너비를 조절합니다. 높이는 화면에 맞춰 유지됩니다. 옵션은 설정 토글 안에 접혀 있습니다.
- Docling이 머리말·꼬리말로 판별한 영역은 번역과 본문 읽기 순서 분석에서 제외합니다. 세로 arXiv 등록 표기도 여기에 해당합니다. 잘못 제외된 본문은 영역 수정에서 본문으로 재분류할 수 있습니다.
- 영역 표시를 켜면 Docling 경계를 확인하고, 분류·제외·경계·분할을 수정해 같은 PDF에서 재사용할 수 있습니다.
- 설정의 문맥 범위는 문자 수입니다. 모델의 토큰 컨텍스트 길이와 같은 단위가 아니며, 입력·출력 합계는 모델 한도를 따릅니다.

선택 가능한 텍스트가 없는 스캔 PDF는 현재 대상이 아닙니다. OCR은 포함하지 않습니다. 암호화·인증이 필요한 PDF는 먼저 내려받아 파일로 여세요.

## 데이터와 이전 설치

설정과 API 키는 이 확장의 `storage.local`에 저장하며 동기화하지 않습니다. 번역·임베딩·영역 수정과 모델은 확장 저장소에 캐시합니다. 원격 번역에는 대상 문장·제목·선택된 주변 문맥을, 원격 임베딩에는 문서 전체의 텍스트 청크와 검색어를 보냅니다. 원격 Docling에는 PDF 전체를 보냅니다. 각 서비스는 선택한 주소에만 요청하며 실패했다고 다른 서버나 로컬 모델로 몰래 전환하지 않습니다. Docling의 캐시·규칙 기반 추출 전환은 위에 설명한 대로 작동합니다.

새 확장 ID이므로 이전 확장의 설정·캐시·수동 영역 수정·모델 다운로드가 자동 이전되지는 않습니다. 이전 확장을 보관하고 새 확장에서 연결 설정을 다시 입력하세요. 같은 논문을 두 확장에서 동시에 자동 열지 않도록 이전 확장을 꺼두는 것을 권합니다. 제거 전에 필요한 수동 수정은 확인하세요. 서버 보존 기간·접속 통제는 운영자가 정합니다. 자세한 내용은 [개인정보 안내](doc/privacy.md)를 참고하세요.

## 개발과 배포

```sh
npm ci
npm test
npm run build
npm run package
```

런타임 직접 의존성은 wllama·ky·webextension-polyfill 세 개입니다. 빌드는 PDF 뷰어, popup, 설정, background, PDF 감지, 브라우저 AI host만 명시적으로 생성합니다. 개발 시 `npm run watch`를 사용하고, 변경 후 `chrome://extensions`에서 새로고침합니다.

[새 PC 확인 목록](doc/testing.md)으로 베타 설치와 사용을 확인하세요. 이 저장소는 Chrome MV3를 대상으로 합니다. 새 PC 최초 설치, 실제 Chrome의 브라우저 WebGPU 전체 경로, Windows/Linux 도우미 설치는 아직 검증을 마치지 않았으며 Firefox·Edge도 별도 확인이 필요합니다. 원격 서버는 설치 예시를 제공하며 자동으로 배포하지 않습니다.
